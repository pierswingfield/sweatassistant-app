## U4-6 — Web Push title, app name & attribution research (2026-10-01)

### 1. Anatomy of the push notification on desktop and iOS

When a notification arrives showing:
```
Psycle: Spot Upgraded
from Sweat Assistant Dev
You're now on Spot 14 for Mon 5 Oct 12:00 Ride Signature 45 with Siân.
```

- **Line 1 (`Psycle: Spot Upgraded`)**: The `title` argument passed to `self.registration.showNotification(title, options)` by `sw.js` (generated by `server/notifications.js`).
- **Line 2 (`from Sweat Assistant Dev`)**: The **system/browser attribution subtitle**, rendered automatically by macOS Notification Center / Apple WebKit.
  - On macOS Safari/Chrome, the OS appends `from <App Name or Origin>`. The app name is derived from the Web App Manifest (`manifest.json` `name`/`short_name`) or the server env var (`APP_NAME`). On the dev twin, `APP_NAME="Sweat Assistant Dev"`; in prod it will be `"Sweat Assistant"`.
  - On iOS (installed Home Screen PWA via Web Push), the banner header displays: `[App Icon] SWEAT ASSISTANT DEV  <time>`, followed by the notification title and body.
  - **Can code remove `from Sweat Assistant Dev`?** No. This line is security-mandated OS attribution identifying the sender origin/app to the user and cannot be suppressed via Web Push options.

### 2. How to make the notification shorter and punchier

1. **Shorten the Title in `server/notifications.js`**:
   The code currently generates titles like `${gym}: Spot Upgraded` and `${gym}: Spot Booked`. Because the app identity is already clear from the icon and the attribution line, these titles can be shortened significantly:
   - `${gym} · Upgraded` (e.g. `Psycle · Upgraded` vs `Psycle: Spot Upgraded`)
   - `${gym} · Booked` (e.g. `Psycle · Booked` vs `Psycle: Spot Booked`)
   - `${gym} · Low Credits` (vs `Psycle: Credit Warning`)
   - `${gym} · Cancel Reminder` (vs `Psycle: Cancellation Deadline`)
   - Or putting key info directly in the title: `Spot 14 Booked` / `Spot 14 Upgraded`.
2. **Shorten the App Attribution (`APP_NAME` / Manifest `short_name`)**:
   - If `short_name` in `manifest.json` (or `APP_NAME` in `.env`) is set to e.g. `"Sweat"`, the OS attribution becomes `from Sweat` (or on iOS banner: `SWEAT`), saving horizontal and vertical space on banners and lock screens.
