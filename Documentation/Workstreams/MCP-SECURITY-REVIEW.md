## Spec/security

Two P2 defects were reproduced and corrected:

1. **Local renewal refusal damaged shared account state.** `server/auth.js:315` previously sent local admission/cancellation/grant refusals into the existing catch-all credential-failure path. It cleared the gym session, changed link status and counted a gym authentication failure. A real exhausted-admission regression failed because RATE_LIMITED became GYM_SESSION_EXPIRED. The fix preserves session/status/counters and propagates local refusal codes. `server/mcp/store.js:73` now normalizes real budget-storage errors as BUDGET_UNAVAILABLE so they cannot enter that credential path. Tests include actual native renewal under an exhausted budget, deadline/grant-policy failures and an actual temporarily missing budget table, without gym HTTP traffic. See `server/test-provider-admission.js:136`.
2. **The bounded timetable contract could return arbitrarily old data.** `server/schedule-cache.js:155` ignored the MCP max-stale intention in its error fallback, while the tool reported five-minute occupancy lag. The new regression failed with a missing expected rejection. `server/normalized-reads.js:120` now opts MCP out of stale-if-error; over-age refresh failures become a safe unavailable result. The PWA keeps its existing fallback and the shared last-good value is retained. See `server/test-schedule-cache.js:100`.
