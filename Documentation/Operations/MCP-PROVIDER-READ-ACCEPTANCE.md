## Source candidate and controlled rollout

`server/mcp/jab-read-window.js` adds the private account/session-bound window. No new public route, global provider flag or background-service flag is needed. `MCP_PROVIDER_READS_ENABLED` stays false and `MCP_STAGE_JAB_PROFILE_ONLY` stays true. The opt-in `MCP_STAGE_JAB_READ_WINDOW_FILE` selects the private configuration for account-specific provider-tool visibility and execution. Without it, existing profile-only behavior is unchanged. While configured, the app denies non-MCP provider traffic and all authentication/profile/refresh paths; after expiry provider tools automatically disappear, and the gateway rejects new or completing read work. Remove the opt-in from both services after the closed window to restore the original authentication/profile-only mode.

Private configuration has exactly six keys: `windowId` (unique 16–100 safe characters), `accountId` (the existing dedicated staging account), `authorizationHash` (SHA-256 of that account's current full JAB Authorization header, computed privately without exporting the token), `day` (one ISO date), `startsAt` and `expiresAt` (integer epoch milliseconds, at most 120 seconds apart). Both services read the same configuration. Mount a dedicated configuration directory read-only into both containers; **do not expose the app's signing keys/client registry to the gateway**. The gateway also needs `MCP_STAGE_JAB_READ_STATE_FILE` in a dedicated persistent directory writable only by it. Config/state files must be mode0600; directories0700. Do not put credentials or configuration values in source, console output or reports.

Gateway admission writes and fsyncs the consumed attempt before contacting JAB. One request is in flight; the six-attempt ledger survives process reconstruction. A changed configuration, corrupt state, stale lock or failed storage operation fails closed. Do not reset/delete the ledger or change configuration while a window may be active; a different configuration cannot reuse the same ledger. Deadline/disconnect, non-200 upstream status and unexpected pagination stop the window. Only the first returned search ID is eligible for detail. No auth/refresh retry is forwarded during the configured mode.
