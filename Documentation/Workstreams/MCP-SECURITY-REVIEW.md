The new regression failed with a missing expected rejection. `server/normalized-reads.js:120` now opts MCP out of stale-if-error; over-age refresh failures become a safe unavailable result. The PWA keeps its existing fallback and the shared last-good value is retained. See `server/test-schedule-cache.js:100`.
